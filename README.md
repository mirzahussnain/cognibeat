# CogniBeat

A Context-Aware Deep Work Engine designed for high-focus professionals and students.

## Project Structure

```
cognibeat/
├── frontend/                 # Next.js 16 application
│   ├── src/                 # Source code
│   ├── public/              # Static assets
│   └── package.json
└── backend/                # Placeholder (TBD)
```

## Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript
- **Styling:** Tailwind CSS v4
- **State:** Zustand
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Theming:** next-themes

## Getting Started

```bash
cd frontend
npm install
npm run dev
```
